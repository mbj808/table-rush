# Table Rush

A one-page multiplication, division, and oceans/seas facts game. Open `index.html` or the GitHub Pages site. No account and no install.

## Modes

- **Multiplication** / **Division** — classic table facts (product, factor, quotient, divisor).
- **Oceans** — quiz on five NOAA oceans plus Mediterranean Sea and Caribbean Sea (seas labeled so kids know they aren't oceans). Clue → name, always 4 choices. Teachers can narrow the set of 7 bodies like table selection.
